GHOSTMODE WEBSITE

HOW TO OPEN:
1. Extract this ZIP file.
2. Open the extracted GhostMode_Multipage folder in Visual Studio Code.
3. Open index.html and click Go Live (if Live Server is installed).
4. Use the navigation menu to move between separate pages.

FILES:
- index.html: Home page
- about.html: About page
- gallery.html: Gallery page
- games.html: Games page
- secret.html: Secret Room page
- contact.html: Contact page
- style.css: Shared design and styling
- script.js: Shared interactive features

YOUR OWN MEDIA:
Copy your image files into this same folder and keep these exact names:
- mypicture.jpg
- mylastpicture.jpg

If you use the music button, also copy your music file into this folder named:
- ghost-music.mp3

The image and music files were not included because they were not part of the original HTML text file.
